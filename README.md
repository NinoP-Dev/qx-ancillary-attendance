# Forest Tracker

A modern web application for tracking attendance and ancillary data, built with React, Vite, and TailwindCSS.

## 🚀 Deployment Status

This project is automatically deployed to Vercel using GitHub Actions.

- **Production URL:** [https://forest-tracker.vercel.app](https://forest-tracker.vercel.app)
- **CI/CD:** GitHub Actions -> Vercel

## 🛠 Tech Stack

- **Framework:** React + Vite
- **Styling:** TailwindCSS
- **Deployment:** Vercel

## 📦 Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run lint` - Lint source code
